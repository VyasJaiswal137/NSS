## 📖 Overview
This repository contains the complete source code for a **single-page Hero Section** designed specifically for the National Service Scheme (NSS) interview portfolio. It was meticulously crafted to replicate a high-fidelity Canva design, emphasizing patriotism, institutional pride, and a clean user experience.

The design centers around the NSS core philosophy, featuring the official motto *"Not Me But You"*, a muted blood-donation camp backdrop, and a subtle Tiranga (tricolor) stripe to represent the nation as a family.

## ✨ Key Features
- **Full-Screen Visual Impact**: Optimized for a 1440x900 canvas, featuring a high-resolution background image of an NSS blood donation camp.
- **Strategic Overlay**: Uses a 70% off-white (`#F8F9FA`) overlay to mute the background, ensuring the NSS logo remains the undisputed focal point while retaining the emotional context of the imagery.
- **Staggered Animations**: Implements smooth "fade-in-up" CSS keyframe animations with staggered delays (0.2s, 0.6s, 1.0s) to perfectly mimic the Canva design timeline.
- **Pixel-Perfect Layout**: Centers the NSS logo, includes a top-right college crest for credibility, and features a distinct NSS Red (`#E31B23`) motto.
- **Patriotic Touches**: Features a mandatory bottom Saffron-White-Green (Tiranga) stripe that sits flush to the edge.
- **Fully Responsive**: Built with Tailwind CSS to adapt beautifully across all device sizes (mobile, tablet, and desktop).

## 🛠️ Tech Stack
- **HTML5** - Semantic structure.
- **CSS3** - Custom keyframes, resets, and animations.
- **Tailwind CSS** (via CDN) - Utility-first styling for rapid, responsive layout.
- **Google Fonts** - **Oswald** (for the bold motto) and **Poppins** (for clean body text).
